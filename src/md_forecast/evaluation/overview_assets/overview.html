What is being predicted?

Each forecast predicts the next values of an observable derived from molecular dynamics. It does not reconstruct an atomistic trajectory, binding affinity or free energy. Continuous regression has no universal accuracy percentage.

MAE is average absolute error in the observable’s native unit. RMSE emphasizes larger misses: it is rooted within each trajectory, then averaged within systems and across independent groups. Skill is 100 × (1 − model MAE / reference MAE); positive values mean less error, not an accuracy rate. Pinball loss scores quantiles; lower is better. 80% coverage is how often truth lies within the 10th–90th percentile interval. Width matters too: broad intervals can cover well without being useful.

Smooth median forecasts may estimate a typical level while missing the timing of fluctuations. The spread ratio quantifies missing variation; matching variation alone would not prove accuracy. Validation guides choices; independent confirmation tests the frozen choices. Overlapping windows and replicas do not create independent complex groups.
