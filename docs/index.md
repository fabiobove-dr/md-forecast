# md-forecast

Forecast future molecular-dynamics-derived observables from partial
protein–ligand trajectories. The scientific task and allowed claims are defined
in the [scientific contract](SCIENTIFIC_CONTRACT.md).

- [Implementation plan](IMPLEMENTATION_PLAN.md): public-data-first research stages.
- [Engineering standards](ENGINEERING_STANDARDS.md): normative implementation rules.
- [Development](DEVELOPMENT.md): setup, configuration, and quality checks.

Current implementation: Python package, validated settings, help/version CLI,
and quality gates. Dataset ingestion, forecasting models, and experiments
are implemented in subsequent issues.
